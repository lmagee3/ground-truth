# Strategic Pivot — 10 May 2026

## Decision

**Skip Phase 1 deployment competition. Accelerate Phase 2 (Diplomat tier) immediately.**

WorldMonitor Pro launched with features that commoditize GT Phase 1:
- Real-time event monitoring (28 MCP tools)
- Stability scoring (137 countries)
- Sanctions tracking, trade flows, chokepoint indices
- AI analyst with full signal stack
- Forecasting / scenario probabilities
- 50K GitHub stars, shipping at insane velocity

Fighting WM on their turf with $2K is suicide. But WM does NOT build:
- Primary source evidence (declassified intel, congressional testimony, treaty texts)
- Citation-rigorous historical context
- Diplomatic recommendation engines
- De-escalation scenario modeling
- Aid allocation optimization

**New positioning:** "WM tells you what's happening. GT tells you what to DO about it."

### New / Accelerated
- **WorldMonitor MCP as input layer** — Replace GDELT/ACLED real-time collection with WM's API. They do it better. We add depth on top.
- **Phase 2 features become Sprint 7-9** (not Sprint 8-12)
- **Recommendation engine** — De-escalation scenarios, intervention scoring, feasibility analysis
- **Diplomatic channel mapping** — Treaty networks, voting alignment, bilateral agreements
- **Aid allocation modeling** — Historical effectiveness + current conditions → ranked strategies
- **Regional Temperature Index** — Composite diplomatic friction score
- **Deploy as API-only first** — No fancy globe/frontend yet. Ship the intelligence as an API that WM users (or any client) can call. Frontend comes after the engine proves value.

## Key Insight

WorldMonitor has 50K stars and ships fast. But Elie is building a *monitoring tool for individuals* (traders, analysts, curious people). His buyer is someone paying $20-50/mo for a dashboard.

GT's buyer is an institution paying $500-2K/mo for *decision support*. Different product, different market, different sale. The UN doesn't buy a monitoring dashboard — they buy an analytical platform that helps them allocate $50B in aid.
